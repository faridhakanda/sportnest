# Project Name: 
### SportNest
# Project Description: 
## SportNest is a online sport stream platform. We are provide our audiences to watch and publish there sport on the platform.

# Feature of the Project:
1. Here our audience can buy and sell sport facility.
2. They can watch there favorite sport different slot on matching there time.
3. They can cancel there booking.
4. They can also edit and delete there added facility.

# Uses Tools and Technology:
1. NextJS with Javascript
2. TailwindCSS
3. React Icons
4. React Toastify
5. JWT
6. Better-auth
7. MongoDB for Database
8. ExpressJS for backend
